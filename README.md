# Skipper Flow

Расширение для Chrome, которое делает просмотр YouTube чище:
- **пропускает рекламные вставки авторов** — спонсорскую рекламу, самопиар и просьбы подписаться;
- **режим стримера** — запикивает мат и оскорбления (и в Shorts), предупреждает заранее;
- **главное в видео** — главы от автора и ключевые моменты от ИИ.

Как работает пропуск рекламы:
1. Сначала ищет готовую разметку в [SponsorBlock](https://sponsor.ajay.app/).
2. Если разметки нет, берёт субтитры видео и отдаёт их ИИ (через [OpenRouter](https://openrouter.ai/)).
3. Найденные фрагменты перематывает и показывает цветом на шкале прогресса.

```
/extension   — расширение Chrome (Manifest V3, чистый JS, без сборки)
/backend     — сервер на Cloudflare Workers + база D1 (анализ ИИ, кэш, отзывы)
/store       — тексты, политика конфиденциальности и картинки для Chrome Web Store
LEARNING.md  — путеводитель по коду для разбора
```

## Что нужно

- Google Chrome (или другой браузер на Chromium).
- Node.js 20 или новее (`node --version`).
- Ключ OpenRouter: https://openrouter.ai/keys (регистрация бесплатная, бесплатные модели работают без пополнения баланса).

> В Windows PowerShell команды `npm` пишите как `npm.cmd` (обычный `npm` блокируется политикой запуска скриптов),
> а вместо `&&` используйте `;` или пишите команды по очереди.

## 1. Запуск сервера локально

Сервер написан для [Cloudflare Workers](https://developers.cloudflare.com/workers/), но локально запускается без аккаунта и без интернета-хостинга — инструментом `wrangler`.

```bash
cd backend
npm install
```

Скопируйте `.dev.vars.example` в `.dev.vars` и впишите ключ в `OPENROUTER_API_KEY` (в PowerShell: `Copy-Item .dev.vars.example .dev.vars`).

Создайте таблицы в локальной базе (один раз):

```bash
npm run db:init:local
```

Запуск:

```bash
npm run dev
```

Сервер будет на http://localhost:8787. Проверка: http://localhost:8787/health — там будет `{"ok":true}`.
При изменении файлов сервер перезапускается сам. Остановить — Ctrl+C.

Остальные настройки (модели, лимиты) — в `backend/wrangler.jsonc`, раздел `vars`.

## 1а. Сервер в интернете (Cloudflare)

Один раз:

1. Зарегистрируйтесь на https://dash.cloudflare.com (бесплатно, карта не нужна).
2. Войдите из терминала: `npm run login` (откроется браузер).
3. Создайте базу: `npm run db:create` — скопируйте `database_id` из вывода в `backend/wrangler.jsonc`.
4. Создайте таблицы: `npm run db:init`.
5. Добавьте ключ как секрет: `npm run secret:key` (команда попросит вставить ключ).
6. Опубликуйте: `npm run deploy` — в выводе будет адрес вида `https://skipper-flow-api.<поддомен>.workers.dev`.

Дальше после изменений в коде сервера — только `npm run deploy`. Логи в реальном времени — `npm run logs`.

Сейчас сервер опубликован по адресу **https://skipper-flow-api.bellka.workers.dev** — расширение использует его по умолчанию.

**Как проверить расширение с локальным сервером:** временно добавьте `"http://localhost/*"` в `host_permissions` в `extension/manifest.json`, укажите `http://localhost:8787` на странице настроек расширения и нажмите ⟳ в `chrome://extensions`. Перед публикацией уберите `localhost` обратно (скрипт сборки об этом напомнит).

## 2. Установка расширения

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика** (переключатель справа вверху).
3. Нажмите **Загрузить распакованное расширение** и выберите папку `extension`.
4. Закрепите иконку Skipper Flow на панели (значок пазла → булавка).

После изменения кода расширения нажмите ⟳ на карточке расширения в `chrome://extensions` и перезагрузите вкладку YouTube.

## 3. Использование

Откройте любое видео на YouTube. Через несколько секунд:
- на шкале прогресса появятся цветные полоски: зелёная — реклама, жёлтая — самореклама, фиолетовая — просьбы подписаться;
- при попадании в такой фрагмент видео перемотается, а внизу слева появится уведомление с кнопками **Посмотреть рекламу** (досмотреть её один раз) и **Это не реклама**.

Иконка расширения открывает popup: там общий выключатель, выключатели по типам, статус текущего видео (источник разметки и число сегментов) и кнопка «Это не реклама» у каждого сегмента.

## Свой ключ OpenRouter (без сервера)

В popup нажмите «Настройки (свой API-ключ)», вставьте ключ и при желании укажите модель.
Тогда расширение ходит в OpenRouter напрямую из background service worker, а backend не нужен
(кроме отзывов «Это не реклама»). Ключ хранится только в `chrome.storage.local` вашего браузера.

## Если не работает

- **«Ошибка анализа: сервер … недоступен»** — backend не запущен или в настройках указан другой адрес.
- **«не задан секрет OPENROUTER_API_KEY»** — локально: нет файла `backend/.dev.vars` или ключ не вписан; в интернете: не выполнена команда `npx wrangler secret put OPENROUTER_API_KEY`.
- **Ошибки HTTP 429** — либо превышен лимит бесплатной модели (сервер сам попробует запасную, у неё должен быть ненулевой баланс на OpenRouter), либо сработал наш лимит запросов (`RATE_LIMIT_PER_MINUTE`, `DAILY_AI_LIMIT` в `wrangler.jsonc`).
- **«Для этого видео анализ недоступен»** — у видео нет субтитров (даже автоматических).
- Логи расширения: `chrome://extensions` → Skipper Flow → ссылка **service worker** (консоль background); консоль вкладки YouTube (F12) — для content script.

## Публикация в Chrome Web Store

Всё для магазина лежит в папке `store/`:
- `store/listing.md` — тексты описания, ответы для раздела «Конфиденциальность», обоснование разрешений и чек-лист перед отправкой;
- `docs/privacy.md` — политика конфиденциальности; папка `docs` публикуется через GitHub Pages, ссылка будет вида `https://<логин>.github.io/<репозиторий>/privacy.html`;
- `store/images/` — промо-картинка 440×280 и скриншоты 1280×800.

Архив для загрузки собирается так (из папки проекта):

```powershell
powershell -ExecutionPolicy Bypass -File pack-extension.ps1
```

Готовый архив появится в `dist/skipper-flow-<версия>.zip`.
